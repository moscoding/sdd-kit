# helpdesk-v1

Учебный сервис поддержки интернет-магазинов из курса «Разработка по спекам». Тикеты, SLA первого ответа в
рабочих минутах магазина и автоназначение операторов. Только стандартная библиотека Python 3.9+.

```bash
python3 -m unittest
```

Спеки текущего поведения — в `docs/specs/`, карта проекта для агента — в `AGENTS.md`.
