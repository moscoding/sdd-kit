# Автоназначение тикетов

Новые тикеты распределяются между операторами так, чтобы покупатель не ждал, пока кто-то возьмёт
тикет вручную.

## Правила

- Тикеты разбирают от самого старого к самому новому.
- Оператор подходит, если он на смене (`shift_start` ≤ сейчас < `shift_end`), знает язык тикета и у
  него есть место: открытые тикеты вместе с назначенными сейчас меньше `max_open`.
- Из подходящих выбирают оператора с наименьшей загрузкой, при равной — с меньшим `id`.
- Если подходящего нет, тикет остаётся без оператора.

## Инварианты

- Тикет назначен не больше чем одному оператору.
- Оператор вне смены не получает тикетов.
- После назначения у оператора не больше `max_open` открытых тикетов.
