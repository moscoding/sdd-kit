# helpdesk-v1

Сервис поддержки интернет-магазинов: тикеты, SLA первого ответа, назначение операторов.
Python 3.9+, только стандартная библиотека.

## Карта

- `helpdesk/models.py` — модели. Интерфейсы новых функций уже описаны здесь: не меняйте поля без спеки.
- `helpdesk/worktime.py` — рабочие минуты магазина (часы, выходные, праздники, часовой пояс).
- `helpdesk/sla.py` — срок первого ответа.
- `helpdesk/assign.py` — автоназначение.
- `docs/specs/` — спеки текущего поведения системы. Новая фича начинается со спеки изменения.
- `tests/` — тесты, `python3 -m unittest` из корня.

## Правила

- Время везде — `datetime` в UTC; местное время магазина — только через `worktime.to_local`.
- Деньги — целые копейки, без `float`.
- Тест, который упал, не ослабляют и не удаляют: чинят код или спрашивают человека.
- Решения, которых нет в спеке, записывают в заметки реализации фичи.
