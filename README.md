# sdd-kit

Учебный набор курса Moscow Coding School «Разработка по спекам»: стартовый проект сервиса поддержки
`helpdesk-v1` и приёмочные проверки практик, в которых фичу пишет ваш агент.

## Как поставить

Нужны Python 3.9 или новее, Git и кодинг-агент: Claude Code, Codex или OpenCode.

```bash
git clone https://github.com/moscoding/sdd-kit
cp -r sdd-kit/starter helpdesk
cd helpdesk
git init && git add . && git commit -m "helpdesk-v1"
python3 -m unittest
```

Получится две соседние папки:

```text
helpdesk/     ваш проект, здесь работает агент
sdd-kit/      набор: стартовая копия и проверки
```

Агента запускайте в папке `helpdesk`. Проверки лежат рядом, а не внутри проекта: агент пишет фичу по
спеке, а не подгоняет код под проверку. Если агент просит открыть `../sdd-kit`, откажите.

Перед новой практикой обновите набор:

```bash
git -C ../sdd-kit pull
```

## Практики

Проверки запускаются из папки `helpdesk`.

| Папка | Модуль | Практика | Проверка |
| --- | --- | --- | --- |
| `escalation/` | 6. Фреймворки и свой процесс | Эскалация по SLA | `python3 ../sdd-kit/escalation/checks/check_escalation.py` |
| `refunds/` | 11. Итоговый проект | Возвраты по политике магазина | `python3 ../sdd-kit/refunds/checks/check_refunds.py` |

Проверка прогоняет сценарии брифа и печатает, какие прошли. Ожидаемые значения она не показывает. Когда
пройдены все сценарии, она печатает код практики — его вводят в уроке.

Все данные синтетические.
